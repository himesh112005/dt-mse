# Design Thinking (BTCOC705C) - Interactive QB Portal

An interactive examination preparation and revision portal for **Design Thinking (BTCOC705C)**, Department of Computer Engineering, SSVPS COE, Dhule.

## ✨ Features
- **30 Verified MCQs**: 10 interactive questions each across CO-01, CO-02, and CO-03 with real-time scoring and detailed explanations.
- **6-Mark Subjective Answers & Visuals**: In-depth evaluation of Silent Brainstorming vs Metaphors vs What-If techniques with an SVG divergence/convergence diagram.
- **Easy Hinglish Quick Revision**: Fast conceptual summaries for exam day.
- **Theme Support**: Seamless Dark Mode / Light Mode with OS system preference detection and persistence.
- **Zero Dependencies**: Pure Vanilla HTML5, CSS3, and JavaScript — ready for instant deployment on Vercel.

## 🚀 Deployment
Deployable directly on [Vercel](https://vercel.com):
- Framework Preset: **Other**
- Root Directory: `./`
- Output Directory: `./`
